# HSH 쇼츠 도우미 — Premiere Pro 패널

롱폼 영상에서 쇼츠를 만드는 반복 작업(채널 틀 · 헤드카피 · 말자막 · 화면 배치 · 기존 자막 블러)을 Premiere Pro 안에서 도와주는 패널의 **배포 · 업데이트 파일**이 올라가는 곳입니다. (소스 코드는 여기 없어요.)

## 처음 설치

1. [최신 릴리스](https://github.com/rippo-cha/hsh-premiere-updates/releases/latest)에서 `HSH-Premiere-v…_Windows_x64.zip` 받기
2. 압축 풀기 → Premiere Pro 끄기 → `설치.bat` 더블클릭
3. Premiere Pro 켜기 → 창(Window) > 확장(Extensions) > **HSH - Highlight Shorts**

자세한 사용법은 zip 안의 `사용법.txt`.

## 업데이트

설치한 뒤에는 여기서 다시 받을 필요 없어요. 패널을 열면 새 버전이 있을 때 위에 알림이 뜨고,
**설정 탭 → 업데이트**에서 [지금 업데이트] 한 번이면 됩니다. 새 버전에 문제가 있으면 같은 곳의 **이전 버전 → 되돌리기**.

- 알림 끄기: 설정 탭 → 업데이트 알림
- 한 버전만 넘기기: 알림의 "다음 버전까지 끄기"

## 필요한 것

Windows 10/11 (64비트), Adobe Premiere Pro 2025 이상 (26.x에서 확인)
